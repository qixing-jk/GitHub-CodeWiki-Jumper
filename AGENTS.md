# Project Agent Guidelines

## Build and generated userscript

- Run `pnpm run build` before `pnpm run test:live`; the live test executes `dist/github-codewiki-jumper.user.js`.
- Treat `dist/github-codewiki-jumper.user.js` as release-managed by `.github/workflows/release-pr.yml`; exclude regenerated bundle changes from ordinary feature and fix commits unless explicitly requested or changing the release pipeline.
- Check `git status --porcelain -- dist/github-codewiki-jumper.user.js` before building. If it already has local changes, preserve them and use an isolated validation path.
- If the bundle was clean before building, restore only the bundle changes generated by the current task after validation and before staging.
